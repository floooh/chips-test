## Controls

- The host keyboard is mapped to the emulated keyboard
- Joystick: arrow keys to move, `Space` to fire (where the title enables a joystick)
- Arcade machines: `1` inserts a coin, `Enter` starts the game
- Drag and drop a file onto the screen to load it

## Debug UI

Open a title through its **DBG** sticker to start the emulator with the debugging interface.
