## About

These are transistor-level simulations of classic 8-bit chips. They are built from netlists extracted from photographs of the real silicon, so every transistor and wire is simulated.

## Using the simulator

- Drag to pan the chip view, use the mouse wheel to zoom
- Use the menu bar to open the debugging windows (memory, disassembler, trace log, assembler)
- Step single half-cycles or let the simulation run continuously
